Producer through-line - what happens today

Retrack This · as of Sept 21, 2026 · charge-upfront Checkout live
Editable working doc for founder / Damian meetings and the community update email.
Yellow boxes = open product questions / gaps to discuss.

One-sentence version. Producer fills out a gig → pays up front at checkout → musicians submit until the deadline → producer favorites takes (no early close) → after the deadline they have 48 hours to award a musician. No award in time with a favorite → we auto-award it. No favorite → refund.

1. Status pills (what the producer sees)

PillCode statusMeaning
DraftPENDING_PAYMENTSaved gig, not paid yet. Private. Can edit, finish payment, or discard.
OpenOPENPaid and live. Musicians can submit. Producer can edit refs/title (not price), cancel+refund, pick takes.
PayingAWARDINGPayout in progress (brief). Retry if stuck.
AwardedAWARDEDWinner paid (or marked for manual PayPal/Wise). Masters unlock.
CancelledCANCELLEDClosed with no award. If money was taken → refunded. Unpaid discard can be restored as Draft.

2. Happy path (decision tree)

START: Producer clicks “Post a job” │ ├─ Fill form (title, refs, instrument, price, deadline 1–7 days, optional invite) │ ├─ “Post job & pay” → creates Draft job + Stripe Embedded Checkout on the page │ ├─ Pay succeeds │ │ → webhook checkout.session.completed (or confirm-checkout fallback) │ │ → Job = Open, payment = captured │ │ → emails: matching musicians + optional invite │ │ │ ├─ “Save as draft” / close checkout without paying │ │ → stays Draft (private). Finish payment later. │ │ │ └─ “Discard draft” │ → Cancelled (no charge). Can Restore as draft if never paid. │ └─ While Open (until deadline - cannot close early): Musicians submit takes (free; need payouts set up) │ ├─ Producer “Favorite this submission” │ → private favorite; job stays Open; can switch favorites │ ├─ Producer “Cancel & refund” │ → refund Stripe charge → Cancelled; musicians notified │ └─ Deadline hits → submissions close → email: “48 hours to award” ├─ Producer “Award this submission” │ → claim AWARDING → transfer → Awarded → masters unlock │ ├─ Has favorite, 48h passes with no click? │ → cron auto-awards that favorite │ └─ No favorite, 48h passes? → cron Cancel & refund

4. Branch: cancel / refund / discard

Discard draft (never paid). No Stripe charge. Job Cancelled. Producer can Restore as draft and try again. Nothing emailed to musicians (job was never public).
Cancel open job (already paid). Full refund via Stripe. Job Cancelled. Musicians who submitted get a cancelled email. Takes stay in DB but job is closed.
Product cost note. Stripe keeps ~2.9%+$0.30 on refunds. Founders still need a written cancel/refund policy for the community email.

5. Branch: deadline with / without a favorite

  • Deadline hits: Submissions close. Producer gets “48 hours to award” email.
  • Favorite saved: Producer can award (or switch) within 48h. Cron auto-awards the favorite if they don’t.
  • No favorite: Same 48h to pick someone. Then cron refunds and cancels.
  • No early “End gig & pay”. Jobs stay open for the full deadline so musicians get an accurate window.
  • Cron is daily on Hobby - the 48h cleanup may wait until the next daily run. Award clicks are instant.

6. Branch: award / payout

  • Musician must have Stripe Connect ready or PayPal/Wise on file.
  • Platform fee ~10%; rest transfers to musician.
  • Alt payout → job Awarded, payment pending_manual_payout until admin pays by hand.
  • Self-award (same account as creator + musician) blocked.
Can producers extend the deadline? Not today. Edit job only changes title, description, reference tracks, and tempo - not price, not deadline. Extending deadline would be a product add (and needs a rule for “already past deadline”).
If they’re not happy with takes? Before award: Cancel & refund (full), or wait out the 48h window with no favorite → auto refund. They cannot end the gig early to stop submissions. After Awarded: no self-serve “undo” - would be support/admin.

7. What musicians see

  • Only Open jobs on the board (Drafts are invisible).
  • Submit free; one submission per job (up to 3 takes inside).
  • Paid only if awarded. Previews available while open; full masters after award for the winner.

8. Payment methods (Checkout)

Stripe Embedded Checkout shows whatever is enabled on the Stripe account: card, Link, Apple Pay, Cash App, Affirm, Klarna, bank, etc. Returning users who used Link before may land on Link first (cookies) - first-time users still get the full method list. Branding colors/logo: Stripe Dashboard → Settings → Branding.
